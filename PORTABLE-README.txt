Bili 查名 v1.2.0 — 支持批量查询的 Windows 64 位便携版

1. 将 ZIP 完整解压，或将解压后的 BiliUidLookup 文件夹完整复制到 U 盘。
2. 双击 BiliUidLookup.exe，浏览器会自动打开查询页面。
3. 默认进入“批量查询”，每行粘贴一个 UID 或空间链接，点击“开始批量查询”。
   一次最多 200 条，结果保留输入顺序和重复项。也可切换“单个查询”。
   支持复制 UID＋昵称、只复制昵称、导出 CSV。
   失败会显示具体原因；停止后可点击“重试未成功项”继续。
4. 用完后关闭程序打开的命令窗口，即可停止本地服务。

运行环境：Windows 10/11 64 位、浏览器、可访问哔哩哔哩的网络。
无需安装 Python，无需管理员权限。
请完整保留 _internal 文件夹，不要只复制 EXE，不要直接在 ZIP 内运行。
源码版本的 start.cmd 需要 Python；本便携版请直接启动 EXE。
升级时先关闭旧版本的命令窗口，再运行新版；请完整替换便携文件夹。
批量结果仅保留在当前页面，请在关闭或刷新前复制、导出。

安全提示说明：
此程序没有代码签名证书。Windows 可能显示“未知发布者”或信誉不足提示；
不同杀毒软件也可能有不同判断，不能保证不会出现提示。
“信誉不足”和“检测到病毒”是不同的提示，应根据实际提示核查文件。
不要为了运行本程序关闭杀毒软件或添加全盘排除。
本程序采用文件夹分发方式、未使用 UPX，不会安装服务或添加开机启动。

源码：https://github.com/ncllw/bilibili-uid-lookup
下载包附有 SHA256 校验文件，可用于核对文件完整性，校验值不等于安全认证。
